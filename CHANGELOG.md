# Changelog

All notable changes to this project will be documented here.

## 0.1.0 - 2026-09-08

### Added

- Six Pi tools for starting, inspecting, reading, interacting with, waiting for, and cancelling background tasks.
- tmux-backed PTY execution with complete log capture and durable terminal results.
- Session-tree-aware task visibility across resume, fork, new-session, and reload transitions.
- Event-driven `/bg-tasks` panel with compact, width-safe task details.
- Batched completion wake-ups, wait deduplication, task timeouts, and runtime ownership isolation.
- English and Simplified Chinese documentation, architecture sources, tests, and release automation.
